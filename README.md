# 桑田学维修：独立接续版本

学习网站：<https://sangtiandetian.github.io/sangtian-repair-study/>

这是从 Muse 成果接续的独立仓库，不向 `muse-weixiu` 推送，不修改 Muse 原站。沿用原来的 19 关、五阶段、主板档案与薄荷绿/浅桃配色。

## 三个分别验收的目标

- 课程：完成 19 关及陌生故障板毕业考。
- 基础：张军《主板维修从入门到精通》第 4 版，全部 13 章、全部小节，按理解、识别、测量与诊断核定。
- 实践：独立定位并修好 10 块主板；建档、正常板点亮与跟做不算独立修复。

已有 MD-006 电池、ATX 链路、POST 与 BIOS 实测不清零。当前第 1 关独立理解验收未确认通过，课程显示 0/19；实践记录单独展示。教材不按关卡数估算百分比。

## 文件与维护

- `index.html`：课程、当前任务、实操证据、教材定位。
- `knowledge.html`：知识库全文检索、分类、原始记录下载、实拍与标注图。
- `boards.html`：7 块主板档案、维修/销售状态和 MD-006 实测。
- `data/curriculum.json`：19 关的目标、步骤、验收、复盘；工具绑定保持交接要求。
- `data/progress.json`：教练核定的当前关卡、验收记录、独立维修、教材状态和下一任务；不提供点击自认证。
- `records/`：本地学习笔记与知识库的独立发布快照，包含原始主板照片与标注图。
- `media/`：原有示范 PPT、25 秒主板视频节选。

本地项目的 Markdown 是实践记录源文件。修改记录后，先导入，再生成发布数据：

```powershell
node scripts/import-project.cjs ..
node scripts/build.cjs
node scripts/check.cjs
```

独立下载本仓库后，可直接修改 `records/` 与 `data/`，运行后两条命令，无须原项目或第三方安装。`import-project.cjs` 只复制指定项目的知识库、学习笔记、照片，不读取聊天数据库、凭据或整个用户目录。

静态文件可以直接打开；所有数据在本地脚本文件中，不依赖服务器 API、不依赖 Muse 原域名。线上 PPT 预览依赖 Microsoft Office 查看服务，失败时仍可下载本仓库 PPT。B站资料是交接文件已有外链，未新增未经确认的付费资料。

## 学习接续规则

一次只安排一个小任务，案例先行，完成后补理论。工作台已够用，不继续扩建拖延学习。保留原有必须/可选/后续需要三级准备清单、安全停止条件、单变量排查和原图测点标注规则。

当完成验收时：记录关卡号、日期、证据文档和复盘；更新 `acceptedLevels` 与 `currentLevel`，更新 `resume` 接续任务，再 build/check/push。已经做过的实践不等于已经独立验收，也不等于整章掌握。

第 4 关前 POST 卡必备，第 8 关 CH341A 可选，第 10 关前焊接套装与练习板准备齐全。工具规则变更需与学习者确认。不会读英文时随实操解释术语，不提前堆英文知识。

教材原书、完整 470 MB 视频、项目压缩包和聊天附件保留在本地，未上传公共仓库。教材按书内/PDF 页码定位；PDF 页码 = 书内页码 + 16。逐小节验收尚待实际教学核定，不能宣称已覆盖全部内容。
