# 主板维修实践知识库

这个知识库随着实践增长。它保存我们已经验证过的认识、实际测量结果、故障推理和容易重复犯的错误；书本目录只用于定位资料和检查覆盖范围。

## 使用方式

每次实践结束后，由我负责完成四件事：

1. 在[学习台账](00-学习台账.md)登记任务、证据、结果和涉及的书本内容。
2. 把可重复使用的原理或方法写成知识卡片。
3. 把具体主板和具体测量过程保存在实操记录中。
4. 遇到故障时，把“现象—假设—测量—排除—结论”沉淀为故障案例。

错误判断和不熟练操作单独进入[错题与误判](04-错题与误判.md)，后续任务会安排再次验证。

## 内容结构

- `01-知识卡片`：跨主板可复用的原理、元器件、信号和测量方法。
- `02-实操记录`：某块主板、某次操作的原始过程和证据。
- `03-故障案例`：围绕故障现象形成的完整诊断闭环。
- `04-错题与误判.md`：概念错误、测量错误和推理漏洞。

## 记录原则

- 先保留事实：主板型号、仪表档位、表笔位置、数值、照片和现象。
- 推断必须写依据；无法验证的内容标记为“待验证”。
- 知识卡片用自己的话写，并链接书内页和对应实践记录。
- 同一结论至少在第二个任务中成功使用一次，才标记为“能独立复现”。
- 老平台专属内容使用 `[旧平台]`，可迁移方法使用 `[通用原理]`，现代平台差异使用 `[现代补充]`。

## 实操开始前

每项实操开始前先给出并确认三类准备清单：

- **必须**：缺少就不能完成本次目标，不开始操作。
- **可选**：能够提高效率或增加证据，但缺少不妨碍主要目标。
- **后续需要**：当前不购买、不占用桌面，到对应步骤前再准备。

清单必须覆盖测试对象、供电、输入输出、显示/反馈、仪表、线材转接、安全用品和记录方式，不能只检查核心元件。

## 实物定位规范

- 涉及元器件或测点定位时，同时提供文字方位和基于库存原图的标注图；明显到无需图片时可以省略。
- 优先使用同一块主板的高清原图，不用外观相近的网络图片代替实际板型。
- 标注前至少核对器件丝印、相邻地标和所属电路布局；三者不能互相支持时标记为“待确认”。
- 标注图只叠加圆圈、箭头和编号，不使用会重绘主板细节的生成式图片。
- 输出前重新检查圆圈是否完整落在目标器件上；发现偏移必须重做，不交付错误标注。
